# Relay HQ Plan

**Goal:** A local command centre (`relay hq`) that shows every project's attention items, runs, plans and tasks, launches work on Claude Code or Codex behind a confirmation, and maps relay's Brain (connectors, API keys, skills, agents, wiring), all from files on disk at zero token cost.
**Spec:** docs/relay/specs/2026-10-21-relay-hq-design.md
**Architecture:** Pure Node modules under `lib/hq/` read the registry, git, the plan/ledger/run files and the harness config files; `lib/hq/server.mjs` serves them as JSON on 127.0.0.1 behind a Host/Origin/token/Content-Type gate, plus a dependency-free ES-module page under `lib/hq/ui/`. Launches are argv built on the server from an action table, run under a detached runner process (`lib/hq/launch-runner.mjs`) that owns the process group and writes `result.json`. `scripts/relay-hq.mjs` is the CLI; `hooks/session-start.mjs` registers repositories; `config/flow.json` describes the pipeline and `relay build` validates it.

## Global Constraints

- Plain Node >= 20, ESM, named exports only, no dependencies, no front-end build. Imports from `node:*` only plus relay's own modules. The mod (`hooks/register.ts`), `agents/`, `codex/` are not touched.
- Start each new file with a 1-3 line comment saying what it is (house style, see `scripts/relay-board.mjs`).
- `<relayHome>` is `relayHome()` from `lib/budget.mjs` (RELAY_HOME or ~/.relay), read at call time, never cached at import. HQ files live in `<relayHome>/hq/`: `registry.json`, `server.json` (mode 0600, dir 0700), `connectors.json`, `verify.json`, `server.log`, `launches/<id>/{launch.json,out.log,result.json,stop.json}`.
- Errors meant for the client are `Object.assign(new Error(message), { status })` with status 400, 403, 404 or 409; the server answers `{ "error": message }` (plus `guards` on 409). Anything without `status` is a 500.
- **No secret value ever leaves the server process.** Brain code keeps key names, `${VAR}` references and booleans only. It never puts a config value, a JSON/TOML parser message (they can quote the file), or raw command output that was not passed through `redact()` into a return value, log line or file.
- Repository key: `realpathSync(mainRoot(path))`. Repository id in URLs (`rid`): first 10 hex chars of `sha1(key)`, from `ridOf()` in `lib/hq/repo.mjs`. Project id: kebab-case of its name at creation; it never changes on rename. Pseudo project for repos without a project: id `_unassigned`, name `Unassigned`.
- Launch ids: `YYYYMMDD-HHMMSS-<4 hex>` (local time), regex `^\d{8}-\d{6}-[0-9a-f]{4}$`. Plans are referenced by their path relative to the repository root, e.g. `docs/relay/plans/x.md`.
- Default port 4747, then the next 10 (4748-4757). Token: 32 random bytes as 64 lowercase hex chars. Page URL `http://127.0.0.1:<port>/#t=<token>`; the page sends `Authorization: Bearer <token>`.
- Cache lifetimes: repository summary 5 s (keyed as in T4), GitHub 120 s, gh auth check 120 s. The page polls every 5 s while visible.
- UI copy is English, short, no explanatory paragraphs in Brain.

#### UI rules and class vocabulary

- ES modules served from `/`: `index.html`, `app.css`, `app.js`, `dom.js`, `launch-dialog.js`, `plan.js`, `brain.js`. Hash routes: `#/`, `#/projects/<id>`, `#/repos/<rid>/plans/<slug>[/tasks/<taskId>]`, `#/brain[/<tab>]` (tabs `connectors|keys|skills|agents|wiring`), `#/launches[/<id>]`.
- Build DOM only with `h()` from `dom.js`. Never `innerHTML`, `insertAdjacentHTML` or `document.write` with any data. Set sizes through `el.style.x = ...` (the CSP forbids style attributes). Only `#/...` hrefs or URLs starting with `https://` become links; external links get `target="_blank" rel="noopener noreferrer"`.
- A view module exports `async render…(main, params, ctx)`, replaces `main`'s children, and may return `{ poll: false }` to opt out of the 5 s refresh. `ctx = { crumbs(items: [label, href?][]), navigate(hash), refresh() }`. View state that must survive a refresh (filters, open tab) lives in module-level variables or the hash.
- Classes (defined in `app.css`, T13): `.top .brand .crumbs .budget .shell .side .two-col .aside .card .grid .row .stack .muted .empty .error .pill .tag .chip .light.grey|.yellow|.green|.red .bar .btn .btn.primary .btn.danger .filters (button[aria-pressed]) .tabs (a[aria-current=page]) table.list .panel .widget .initials .waves .wave .lane .task .task[aria-selected=true] .step .step.cli .flow .group .tier-cheap .tier-mid .tier-strong pre.code`.

## Review Focus

- Secrets: no parser message, config value, stdio `args`, raw `claude mcp list` output (unless redacted) or settings value reaches a response. The test only covers parsable fixtures; check the unreadable and Verify paths by reading.
- XSS: every string from a plan, ledger, PR title, skill description or log is untrusted; confirm no HTML sink in `lib/hq/ui/*` and that only `#/` or `https://` hrefs are built.
- `/api/open`: realpath before the prefix check (symlinks out of a repo), separator-aware prefix, and the OS opener reveals files instead of executing them.
- Launch argv: built only from the action table; every prompt starts with a fixed non-dash prefix (`/relay:`, `Use the`, or a command body), so user text can never become a flag; the dangerous permission mode is enforced on the server, not only by the checkbox.
- Process lifecycle: stop signals the group (`-pid`), a server restart reads status from files, a dead runner without `result.json` shows `lost`, and the server never crashes on a child `error` event.
- Concurrent `session-start` hooks: atomic rename keeps the registry valid; a lost `lastSeenAt` update is accepted. A damaged `registry.json` must never be replaced by an empty one.
- Spec section 11 is unverified on this machine: Codex flags (`codex exec -m -c model_reasoning_effort --sandbox --json`), Codex effort values, `codex mcp list`, Codex's `CODEX_*` variable, whether headless `claude -p` runs `/relay:*` slash commands and sees claude.ai account connectors. All Codex values sit in `HARNESS.codex` in `lib/hq/launch.mjs`.
- Deliberate deviations from the spec text: Claude argv also carries `--session-id <uuid>` (as marathon does, so a child never writes into the parent's transcript) and `--dangerously-skip-permissions` with `bypassPermissions`; `RELAY_HARNESS` beats `CLAUDECODE=1` in harness detection (HQ's server inherits `CLAUDECODE=1` when started from `/relay:hq`); `env` in `~/.claude/settings.json` counts as `set`, not `in-file`; `relay hq` prints the tokened URL only with `--no-open`.

```js
// relay HQ's registry: projects (named groups of repositories), repositories and
// their hidden flags, in <relayHome>/hq/registry.json. Writes are atomic (temp
// file + rename). A repository's key is the realpath of its main worktree root.

import { existsSync, mkdirSync, readFileSync, realpathSync, renameSync, writeFileSync } from 'node:fs';
import { dirname, join, resolve } from 'node:path';
import { relayHome } from '../budget.mjs';
import { mainRoot } from '../git.mjs';

const bad = (message) => Object.assign(new Error(message), { status: 400 });
const has = (reg, repo) => typeof repo === 'string' && Object.hasOwn(reg.repos, repo);

export function registryPath() {
  return join(relayHome(), 'hq', 'registry.json');
}

export function emptyRegistry() {
  return { version: 1, projects: [], repos: {} };
}

// A missing file is an empty registry; a damaged one is an error, never silently replaced.
export function readRegistry(path = registryPath()) {
  if (!existsSync(path)) return emptyRegistry();
  let reg;
  try {
    reg = JSON.parse(readFileSync(path, 'utf8'));
  } catch {
    throw new Error(`${path} is not valid JSON; fix or remove it`);
  }
  if (reg?.version !== 1 || !Array.isArray(reg.projects) || !reg.repos || typeof reg.repos !== 'object') {
    throw new Error(`${path} is not a relay HQ registry (version 1)`);
  }
  return reg;
}

export function writeRegistry(reg, path = registryPath()) {
  mkdirSync(dirname(path), { recursive: true });
  const tmp = `${path}.${process.pid}.tmp`;
  writeFileSync(tmp, JSON.stringify(reg, null, 2) + '\n');
  renameSync(tmp, path);
}

export function updateRegistry(change, path = registryPath()) {
  const reg = readRegistry(path);
  const result = change(reg);
  writeRegistry(reg, path);
  return result;
}

export function projectId(name) {
  const id = String(name ?? '')
    .normalize('NFKD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
  if (!id) throw bad(`project name "${name}" has no letters or digits`);
  return id;
}

// The main checkout's real path, also from a subdirectory or a lane worktree; undefined outside git.
export function repoKey(path) {
  const root = mainRoot(resolve(path));
  if (!root) return undefined;
  try {
    return realpathSync(root);
  } catch {
    return undefined;
  }
}

// Called by session-start on every session: registers once, afterwards only lastSeenAt moves.
export function touchRepo(path, via, now = new Date()) {
  const key = repoKey(path);
  if (!key) return undefined;
  updateRegistry((reg) => {
    const at = now.toISOString();
    if (has(reg, key)) reg.repos[key].lastSeenAt = at;
    else reg.repos[key] = { addedAt: at, lastSeenAt: at, hidden: false, via };
  });
  return key;
}

export function addRepo(path, { project, now = new Date() } = {}) {
  const key = repoKey(path);
  if (!key) throw bad(`not a git repository: ${path}`);
  touchRepo(key, 'cli', now);
  if (project) {
    updateRegistry((reg) => {
      const id = ensureProject(reg, project);
      assign(reg, key, id);
    });
  }
  return key;
}

function ensureProject(reg, name) {
  const id = projectId(name);
  if (!reg.projects.some((p) => p.id === id)) reg.projects.push({ id, name: String(name).trim(), repos: [] });
  return id;
}

function assign(reg, repo, id) {
  if (!has(reg, repo)) throw bad(`not registered: ${repo}`);
  if (id !== null && !reg.projects.some((p) => p.id === id)) throw bad(`unknown project: ${id}`);
  for (const p of reg.projects) p.repos = p.repos.filter((r) => r !== repo);
  if (id !== null) reg.projects.find((p) => p.id === id).repos.push(repo);
}

// op: { op: 'create-project', name } | { op: 'rename-project', id, name }
//   | { op: 'assign', repo, project: id | null } | { op: 'hide' | 'unhide' | 'remove', repo }
// Mutates reg; throws a status-400 error on bad input.
export function applyRegistryOp(reg, op) {
  switch (op?.op) {
    case 'create-project':
      return { id: ensureProject(reg, op.name) };
    case 'rename-project': {
      const p = reg.projects.find((x) => x.id === op.id);
      if (!p) throw bad(`unknown project: ${op.id}`);
      projectId(op.name); // the new name needs letters or digits; the id stays so links keep working
      p.name = String(op.name).trim();
      return { id: p.id };
    }
    case 'assign':
      assign(reg, op.repo, op.project ?? null);
      return {};
    case 'hide':
    case 'unhide':
      if (!has(reg, op.repo)) throw bad(`not registered: ${op.repo}`);
      reg.repos[op.repo].hidden = op.op === 'hide';
      return {};
    case 'remove':
      if (!has(reg, op.repo)) throw bad(`not registered: ${op.repo}`);
      delete reg.repos[op.repo];
      for (const p of reg.projects) p.repos = p.repos.filter((r) => r !== op.repo);
      return {};
    default:
      throw bad(`unknown registry operation: ${op?.op}`);
  }
}

export function listRepos(reg) {
  return Object.entries(reg.repos).map(([path, meta]) => ({
    path,
    ...meta,
    project: reg.projects.find((p) => p.repos.includes(path))?.id ?? null,
  }));
}
```

```js
#!/usr/bin/env node
// SessionStart: inject the using-relay rules (and the budget level when known),
// then register the session's repository with relay HQ, best effort, after the
// rules are out. Works for Claude Code (plugin hook) and Codex (project .codex/hooks.json).

import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { describeWindows, isStale, levelFor, readSnapshot } from '../lib/budget.mjs';
import { stripFrontmatter } from '../lib/frontmatter.mjs';
import { readInput, writeContext } from '../lib/hookio.mjs';
import { loadRouting, RELAY_ROOT } from '../lib/routing.mjs';

try {
  const input = await readInput().catch(() => ({}));
  const rules = stripFrontmatter(readFileSync(join(RELAY_ROOT, 'skills', 'using-relay', 'SKILL.md'), 'utf8')).trim();
  let budgetLine = '';
  const routing = loadRouting();
  const snap = readSnapshot();
  if (snap && !isStale(snap, routing.budget.staleAfterMinutes)) {
    budgetLine = `\n\nRelay budget at session start: ${levelFor(snap, routing.budget)} (${describeWindows(snap)}).`;
  }
  writeContext('SessionStart', `<relay-rules>\n${rules}${budgetLine}\n</relay-rules>`);
  await registerWithHq(input);
  process.exit(0);
} catch (err) {
  // Never block a session over the bootstrap.
  process.stderr.write(`relay session-start: ${err.message}\n`);
  process.exit(0);
}

// The repository joins relay HQ's registry, or only its lastSeenAt moves. Never
// changes a project or a hidden flag; outside git it does nothing; errors are swallowed.
async function registerWithHq(input) {
  try {
    const { touchRepo } = await import('../lib/hq/registry.mjs');
    touchRepo(typeof input?.cwd === 'string' && input.cwd ? input.cwd : process.cwd(), 'session-start');
  } catch {
    // HQ registration never affects a session start
  }
}
```

### T2: TOML subset and harness sources
Create `lib/hq/toml.mjs` exactly as below. Errors carry only a line number and a short reason, never file content.

```js
// A TOML subset: enough for ~/.codex/config.toml and Codex agent files. Tables,
// arrays of tables, dotted and quoted keys, basic/literal/multi-line strings,
// integers, floats, booleans, arrays and inline tables; dates stay strings.
// parseToml never throws: { ok: true, value } or { ok: false, error: 'line N: ...' }.

export function parseToml(text) {
  try {
    return { ok: true, value: new Parser(String(text)).document() };
  } catch (err) {
    return { ok: false, error: err.message };
  }
}

const isTable = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);
const BARE = /[A-Za-z0-9_-]+/y;
const ATOM = /[0-9A-Za-z_+\-.:]+/y;
const ESCAPES = { b: '\b', t: '\t', n: '\n', f: '\f', r: '\r', e: '\x1b', '"': '"', '\\': '\\' };

class Parser {
  constructor(src) {
    this.src = src.replace(/\r\n/g, '\n');
    this.i = 0;
    this.root = {};
  }

  fail(msg) {
    const line = this.src.slice(0, this.i).split('\n').length;
    throw new Error(`line ${line}: ${msg}`);
  }

  peek() {
    return this.src[this.i];
  }

  at(s) {
    return this.src.startsWith(s, this.i);
  }

  skipWs() {
    while (this.peek() === ' ' || this.peek() === '\t') this.i++;
  }

  skipComment() {
    if (this.peek() === '#') while (this.i < this.src.length && this.peek() !== '\n') this.i++;
  }

  skipBlank() {
    for (;;) {
      this.skipWs();
      this.skipComment();
      if (this.peek() !== '\n') return;
      this.i++;
    }
  }

  endOfLine() {
    this.skipWs();
    this.skipComment();
    if (this.i < this.src.length && this.peek() !== '\n') this.fail('unexpected text after a value');
    this.i++;
  }

  document() {
    let current = this.root;
    for (;;) {
      this.skipBlank();
      if (this.i >= this.src.length) return this.root;
      if (this.at('[[')) {
        this.i += 2;
        const path = this.keyPath();
        this.skipWs();
        if (!this.at(']]')) this.fail('expected ]]');
        this.i += 2;
        current = this.arrayTable(path);
      } else if (this.peek() === '[') {
        this.i++;
        const path = this.keyPath();
        this.skipWs();
        if (this.peek() !== ']') this.fail('expected ]');
        this.i++;
        current = this.table(this.root, path);
      } else {
        this.keyValue(current);
      }
      this.endOfLine();
    }
  }

  keyPath() {
    const parts = [];
    for (;;) {
      this.skipWs();
      parts.push(this.key());
      this.skipWs();
      if (this.peek() !== '.') return parts;
      this.i++;
    }
  }

  key() {
    let k;
    if (this.peek() === '"') k = this.basicString();
    else if (this.peek() === "'") k = this.literalString();
    else {
      BARE.lastIndex = this.i;
      const m = BARE.exec(this.src);
      if (!m) this.fail('expected a key');
      this.i += m[0].length;
      k = m[0];
    }
    if (k === '__proto__') this.fail('unsupported key');
    return k;
  }

  descend(t, k) {
    if (t[k] === undefined) t[k] = {};
    const v = t[k];
    if (Array.isArray(v) && isTable(v[v.length - 1])) return v[v.length - 1];
    if (!isTable(v)) this.fail(`"${k}" is not a table`);
    return v;
  }

  table(base, path) {
    let t = base;
    for (const k of path) t = this.descend(t, k);
    return t;
  }

  arrayTable(path) {
    const parent = this.table(this.root, path.slice(0, -1));
    const k = path[path.length - 1];
    if (parent[k] === undefined) parent[k] = [];
    if (!Array.isArray(parent[k])) this.fail(`"${k}" is not an array of tables`);
    const t = {};
    parent[k].push(t);
    return t;
  }

  keyValue(target) {
    const path = this.keyPath();
    this.skipWs();
    if (this.peek() !== '=') this.fail('expected =');
    this.i++;
    this.skipWs();
    const value = this.value();
    const t = this.table(target, path.slice(0, -1));
    const k = path[path.length - 1];
    if (Object.hasOwn(t, k)) this.fail(`duplicate key "${k}"`);
    t[k] = value;
  }

  value() {
    if (this.at('"""')) return this.multiBasic();
    if (this.at("'''")) return this.multiLiteral();
    const c = this.peek();
    if (c === '"') return this.basicString();
    if (c === "'") return this.literalString();
    if (c === '[') return this.array();
    if (c === '{') return this.inlineTable();
    ATOM.lastIndex = this.i;
    const m = ATOM.exec(this.src);
    if (!m) this.fail('expected a value');
    this.i += m[0].length;
    const s = m[0];
    if (s === 'true') return true;
    if (s === 'false') return false;
    if (/^[+-]?(0|[1-9](_?\d)*)$/.test(s)) return Number(s.replace(/_/g, ''));
    if (/^0x[0-9a-fA-F](_?[0-9a-fA-F])*$/.test(s)) return parseInt(s.slice(2).replace(/_/g, ''), 16);
    if (/^[+-]?(0|[1-9](_?\d)*)(\.\d(_?\d)*)?([eE][+-]?\d(_?\d)*)?$/.test(s)) return Number(s.replace(/_/g, ''));
    if (/^[+-]?(inf|nan)$/.test(s)) return s.endsWith('nan') ? NaN : s.startsWith('-') ? -Infinity : Infinity;
    if (/^\d{4}-\d{2}-\d{2}/.test(s) || /^\d{2}:\d{2}/.test(s)) return s;
    return this.fail('invalid value');
  }

  escape() {
    const c = this.src[this.i++];
    if (c !== undefined && Object.hasOwn(ESCAPES, c)) return ESCAPES[c];
    if (c === 'u' || c === 'U') {
      const n = c === 'u' ? 4 : 8;
      const hex = this.src.slice(this.i, this.i + n);
      if (hex.length !== n || !/^[0-9a-fA-F]+$/.test(hex)) this.fail('bad unicode escape');
      this.i += n;
      return String.fromCodePoint(parseInt(hex, 16));
    }
    return this.fail('bad escape');
  }

  basicString() {
    this.i++;
    let out = '';
    for (;;) {
      const c = this.peek();
      if (c === undefined || c === '\n') this.fail('unterminated string');
      this.i++;
      if (c === '"') return out;
      out += c === '\\' ? this.escape() : c;
    }
  }

  literalString() {
    this.i++;
    const end = this.src.indexOf("'", this.i);
    const nl = this.src.indexOf('\n', this.i);
    if (end === -1 || (nl !== -1 && nl < end)) this.fail('unterminated string');
    const s = this.src.slice(this.i, end);
    this.i = end + 1;
    return s;
  }

  multiBasic() {
    this.i += 3;
    if (this.peek() === '\n') this.i++;
    let out = '';
    for (;;) {
      if (this.i >= this.src.length) this.fail('unterminated string');
      if (this.at('"""')) {
        this.i += 3;
        for (let extra = 0; extra < 2 && this.peek() === '"'; extra++) {
          out += '"';
          this.i++;
        }
        return out;
      }
      const c = this.src[this.i++];
      if (c !== '\\') {
        out += c;
        continue;
      }
      const fold = /[ \t]*\n\s*/y;
      fold.lastIndex = this.i;
      const m = fold.exec(this.src);
      if (m) this.i += m[0].length;
      else out += this.escape();
    }
  }

  multiLiteral() {
    this.i += 3;
    if (this.peek() === '\n') this.i++;
    let end = this.src.indexOf("'''", this.i);
    if (end === -1) this.fail('unterminated string');
    for (let extra = 0; extra < 2 && this.src[end + 3] === "'"; extra++) end++;
    const s = this.src.slice(this.i, end);
    this.i = end + 3;
    return s;
  }

  array() {
    this.i++;
    const out = [];
    for (;;) {
      this.skipBlank();
      if (this.peek() === ']') {
        this.i++;
        return out;
      }
      out.push(this.value());
      this.skipBlank();
      if (this.peek() === ',') {
        this.i++;
        continue;
      }
      if (this.peek() === ']') {
        this.i++;
        return out;
      }
      this.fail('expected , or ] in an array');
    }
  }

  inlineTable() {
    this.i++;
    const t = {};
    this.skipWs();
    if (this.peek() === '}') {
      this.i++;
      return t;
    }
    for (;;) {
      this.skipWs();
      this.keyValue(t);
      this.skipWs();
      if (this.peek() === ',') {
        this.i++;
        continue;
      }
      if (this.peek() === '}') {
        this.i++;
        return t;
      }
      this.fail('expected , or } in an inline table');
    }
  }
}
```

```js
export const KEY_RE = /(_API_KEY|_TOKEN|_SECRET|_ACCESS_KEY|_ACCESS_KEY_ID)$/;
const KEY_IN_TEXT = /\b[A-Z][A-Z0-9_]*(?:_API_KEY|_TOKEN|_SECRET|_ACCESS_KEY|_ACCESS_KEY_ID)\b/g;
const AUTH_HEADER = /authorization|api[-_]?key|token|secret/i;
const isObj = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);

// Variable names a config string references: ${VAR}, ${VAR:-default}, $VAR.
export function refsIn(value) {
  if (typeof value !== 'string') return [];
  return [...value.matchAll(/\$\{([A-Za-z_][A-Za-z0-9_]*)(?::-[^}]*)?\}|\$([A-Za-z_][A-Za-z0-9_]*)/g)].map((m) => m[1] ?? m[2]);
}

const literal = (v) => typeof v === 'string' && v.trim() !== '' && refsIn(v).length === 0;

// Masks anything that looks like a credential in command output shown to the page.
export function redact(text) {
  return String(text ?? '')
    .replace(/((?:bearer|token|key|secret|password)\S*(?:\s*[:=]\s*|\s+))\S+/gi, '$1•••')
    .replace(/[A-Za-z0-9_\-]{24,}/g, '•••');
}

// What HQ keeps of one MCP server config: names and flags, never a value.
export function describeServer(name, cfg, { harness, source, file }) {
  const needs = new Set();
  const literals = [];
  for (const s of [cfg?.url, cfg?.command, ...(Array.isArray(cfg?.args) ? cfg.args : [])]) for (const r of refsIn(s)) needs.add(r);
  const headers = { ...(isObj(cfg?.headers) ? cfg.headers : {}), ...(isObj(cfg?.http_headers) ? cfg.http_headers : {}) };
  for (const [h, v] of Object.entries(headers)) {
    for (const r of refsIn(v)) needs.add(r);
    if (AUTH_HEADER.test(h) && literal(v)) literals.push({ where: `header ${h}` });
  }
  for (const [k, v] of Object.entries(isObj(cfg?.env) ? cfg.env : {})) {
    for (const r of refsIn(v)) needs.add(r);
    if (KEY_RE.test(k) && literal(v)) literals.push({ where: `env ${k}`, key: k });
  }
  const bearer = typeof cfg?.bearer_token_env_var === 'string' ? cfg.bearer_token_env_var : undefined;
  if (bearer) needs.add(bearer);
  for (const v of Array.isArray(cfg?.env_vars) ? cfg.env_vars : []) if (typeof v === 'string') needs.add(v);
  for (const v of Object.values(isObj(cfg?.env_http_headers) ? cfg.env_http_headers : {})) if (typeof v === 'string') needs.add(v);
  const http = typeof cfg?.url === 'string' || cfg?.type === 'http' || cfg?.type === 'sse';
  return {
    name,
    harness,
    source,
    file,
    kind: http ? 'mcp-http' : 'mcp-stdio',
    needs: [...needs].filter((n) => KEY_RE.test(n) || n === bearer).sort(),
    literals,
    hasAuth: needs.size > 0 || Object.keys(headers).some((h) => AUTH_HEADER.test(h)),
  };
}
```

```js
const two = (n) => String(n).padStart(2, '0');
export function newLaunchId(now = new Date()) {
  const day = `${now.getFullYear()}${two(now.getMonth() + 1)}${two(now.getDate())}`;
  const time = `${two(now.getHours())}${two(now.getMinutes())}${two(now.getSeconds())}`;
  return `${day}-${time}-${randomBytes(2).toString('hex')}`;
}

function readJson(path) {
  try {
    return JSON.parse(readFileSync(path, 'utf8'));
  } catch {
    return undefined;
  }
}

function writeJsonAtomic(path, value) {
  const tmp = `${path}.${process.pid}.tmp`;
  writeFileSync(tmp, JSON.stringify(value, null, 2) + '\n');
  renameSync(tmp, path);
}

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

// spec: { action, repo, plan, harness, bin, argv, cwd, model, effort, permissionMode, env, display }
export function startLaunch(spec, { now = new Date() } = {}) {
  const id = newLaunchId(now);
  const dir = join(launchesDir(), id);
  mkdirSync(dir, { recursive: true });
  const record = {
    id,
    action: spec.action,
    repo: spec.repo ?? null,
    plan: spec.plan ?? null,
    harness: spec.harness,
    bin: spec.bin,
    argv: spec.argv,
    cwd: spec.cwd,
    env: spec.env ?? {},
    model: spec.model ?? null,
    effort: spec.effort ?? null,
    permissionMode: spec.permissionMode ?? null,
    display: spec.display ?? null,
    startedAt: now.toISOString(),
    pid: null,
  };
  writeJsonAtomic(join(dir, 'launch.json'), record);
  const out = openSync(join(dir, 'out.log'), 'a');
  let child;
  try {
    child = spawn(process.execPath, [RUNNER, dir], { cwd: dir, detached: true, stdio: ['ignore', out, out] });
  } finally {
    closeSync(out);
  }
  child.on('error', (err) => writeJsonAtomic(join(dir, 'result.json'), { status: 'failed', exitCode: null, error: err.message, endedAt: new Date().toISOString() }));
  child.unref();
  if (child.pid) writeJsonAtomic(join(dir, 'launch.json'), { ...record, pid: child.pid });
  return getLaunch(id);
}

export function getLaunch(id) {
  if (!ID_RE.test(String(id))) return undefined;
  const dir = join(launchesDir(), id);
  const launch = readJson(join(dir, 'launch.json'));
  if (!launch) return undefined;
  const result = readJson(join(dir, 'result.json'));
  const status = result?.status ?? (alive(launch.pid) ? 'running' : existsSync(join(dir, 'stop.json')) ? 'stopped' : 'lost');
  const endedAt = result?.endedAt ?? null;
  const { env, ...pub } = launch;
  return {
    ...pub,
    status,
    endedAt,
    exitCode: result?.exitCode ?? null,
    costUsd: result?.costUsd ?? null,
    usage: result?.usage ?? null,
    error: result?.error ?? null,
    durationMs: (endedAt ? Date.parse(endedAt) : Date.now()) - Date.parse(launch.startedAt),
  };
}

export function listLaunches({ limit = 200 } = {}) {
  let ids;
  try {
    ids = readdirSync(launchesDir()).filter((d) => ID_RE.test(d));
  } catch {
    return [];
  }

}

export function logTail(id, bytes = 64 * 1024) {
  if (!ID_RE.test(String(id))) return '';
  const path = join(launchesDir(), id, 'out.log');
  try {
    const size = statSync(path).size;
    const start = Math.max(0, size - bytes);
    const fd = openSync(path, 'r');
    try {
      const buf = Buffer.alloc(size - start);
      readSync(fd, buf, 0, buf.length, start);
      return buf.toString('utf8');
    } finally {
      closeSync(fd);
    }
  } catch {
    return '';
  }
}

// SIGTERM to the launch's process group, SIGKILL after 10 seconds; recorded as stopped.
export async function stopLaunch(id, { graceMs = STOP_GRACE_MS } = {}) {
  const launch = getLaunch(id);
  if (!launch) throw Object.assign(new Error('unknown launch'), { status: 404 });
  if (launch.status !== 'running') return launch;
  const dir = join(launchesDir(), id);
  writeJsonAtomic(join(dir, 'stop.json'), { requestedAt: new Date().toISOString() });
  const signal = (sig) => {
    try {
      process.kill(-launch.pid, sig);
    } catch {
      // already gone
    }
  };
  const over = () => existsSync(join(dir, 'result.json')) || !alive(launch.pid);
  signal('SIGTERM');
  for (const until = Date.now() + graceMs; !over() && Date.now() < until; ) await sleep(100);
  if (!over()) {
    signal('SIGKILL');
    for (const until = Date.now() + 2000; alive(launch.pid) && Date.now() < until; ) await sleep(100);
  }
  if (!existsSync(join(dir, 'result.json'))) writeJsonAtomic(join(dir, 'result.json'), { status: 'stopped', exitCode: null, endedAt: new Date().toISOString() });
  return getLaunch(id);
}
```

```js
const LEDGER_LINE = /^- (\d{4}-\d{2}-\d{2}) (\d{2}:\d{2})(?: \[[^\]]*\])? (.*)$/;
const QUIET_MS = 30 * 60_000;

// Is the plan alive, or can a run resume it? { refuse: reason } when something looks
// alive, { resume: true } for a started, unfinished plan whose board is blocked or
// whose ledger has been quiet for 30 minutes, {} for a plan that never started.
function runState(i, planAbs, launches, now) {
  if (launches.some((l) => l.status === 'running' && (l.action === 'run' || l.action === 'marathon') && l.repo === i.repo && planInRepo(l.repo, l.plan) === planAbs)) return { refuse: 'an HQ launch is running it' };
  let slug;
  try {
    slug = parsePlan(readFileSync(planAbs, 'utf8')).slug;
  } catch {
    return {};
  }
  const dir = runDir(planAbs, slug);
  const marathon = readJson(join(dir, 'marathon.json'));
  if (marathon && !marathon.endedAt && alive(marathon.pid)) return { refuse: 'a marathon is running it' };
  const ledgerPath = join(dir, 'ledger.md');
  const entries = (existsSync(ledgerPath) ? readFileSync(ledgerPath, 'utf8') : '')
    .split('\n')
    .map((l) => LEDGER_LINE.exec(l))
    .filter(Boolean)
    .map((m) => ({ at: Date.parse(`${m[1]}T${m[2]}:00`), text: m[3].trim() }));
  const started = entries.some((e) => /^start:/.test(e.text));
  if (!started || entries.some((e) => /^plan: complete/.test(e.text))) return {};
  const r = boardFor(planAbs);
  if (r.board?.status === 'blocked') return { resume: true };
  const last = entries[entries.length - 1].at;
  if (Number.isFinite(last) && now - last < QUIET_MS) return { refuse: 'its ledger moved less than 30 minutes ago' };
  return { resume: true };
}

export function evaluateGuards(i, { env = process.env, routing = loadRouting(), registry = readRegistry(), launches = listLaunches(), now = Date.now() } = {}) {
  const errors = [];
  const warnings = [];
  if (!ACTIONS.includes(i.action)) return { errors: [`unknown action: ${i.action}`], warnings };
  const opts = launchOptions(i.harness, routing, i.action);
  if (!opts) return { errors: [`unknown harness: ${i.harness}`], warnings };
  if (i.action !== 'connectors' || i.repo !== undefined) {
    if (!i.repo || !Object.hasOwn(registry.repos, i.repo)) errors.push('the repository is not registered');
    else if (!existsSync(i.repo)) errors.push('the repository is missing on disk');
  }
  const planned = i.action === 'run' || i.action === 'marathon';
  let resume = false;
  const planAbs = planned && !errors.length ? planInRepo(i.repo, i.plan) : undefined;
  if (planned && !errors.length && !planAbs) errors.push('the plan is not a file under docs/relay/plans/');
  if (i.action === 'marathon' && i.harness !== 'claude') errors.push('marathon runs on Claude Code only in this version');
  if (i.action === 'setup-codex' && i.harness !== 'codex') errors.push('setup-codex is a Codex action');
  if (i.action !== 'setup-codex' && i.harness === 'claude' && !resolveClaudeBin(env)) errors.push('claude not found: put it on PATH or set RELAY_CLAUDE_BIN');
  if (i.action !== 'setup-codex' && i.harness === 'codex' && !codexBin(env)) errors.push('codex is not installed');
  if (i.action === 'plan' && !i.goal) errors.push('a plan needs a goal');
  if (i.action === 'skill' && (!/^[a-z0-9][a-z0-9:_-]*$/i.test(i.skill) || !i.prompt)) errors.push('a skill launch needs a skill name and a prompt');
  if (i.goal.length > MAX_TEXT || i.prompt.length > MAX_TEXT) errors.push(`text is longer than ${MAX_TEXT} characters`);
  if (i.action !== 'setup-codex') {
    if (!opts.models.includes(i.model)) errors.push(`model must be one of ${opts.models.join(', ')}`);
    if (i.action !== 'marathon' && !opts.efforts.includes(i.effort)) errors.push(`effort must be one of ${opts.efforts.join(', ')}`);
    if (!opts.modes.includes(i.permissionMode)) errors.push(`permission mode must be one of ${opts.modes.join(', ')}`);
    if (i.permissionMode === opts.dangerous && !i.confirmDangerous) errors.push(`${opts.dangerous} needs the extra confirmation`);
  }
  if (i.action === 'marathon' && !(Number.isFinite(i.hours) && i.hours >= 1 && i.hours <= 48)) errors.push('hours must be between 1 and 48');
  if (planAbs) {
    const state = runState(i, planAbs, launches, now);
    if (state.refuse) errors.push(`the plan is already running (${state.refuse})`);
    if (state.resume) {
      resume = true;
      warnings.push('resumes from the ledger');
    }
    const level = budgetNow(routing)?.level;
    if (level === 'critical') errors.push('the budget is critical; wait for the window to reset');
    else if (level === 'tight') warnings.push('the budget is tight');
  }
  return { errors, warnings, planAbs, resume };
}

function prepare(raw, ctx = {}) {
  const routing = ctx.routing ?? loadRouting();
  const i = normalizeIntent(raw, routing);
  const { errors, warnings, planAbs, resume } = evaluateGuards(i, { ...ctx, routing });
  if (planAbs) i.plan = relative(i.repo, planAbs).split(sep).join('/');
  let command;
  try {
    command = buildCommand(i, ctx);
    command.display = displayCommand(command, i.harness);
  } catch (err) {
    errors.push(err.message);
  }
  let forecast;
  let hint;
  if (planAbs) {
    const f = forecastPlan(planAbs);
    if (!f.errors.length) {
      forecast = f.forecast;
      if (i.action === 'run' && (forecast.usage?.windows ?? 1) > 1) hint = 'This plan spans more than one 5-hour window: consider Marathon.';
    }
  }
  return { i, command, guards: { errors, warnings }, resume, forecast, hint, budget: budgetNow(routing), options: launchOptions(i.harness, routing, i.action) ?? null };
}

export function previewLaunch(raw, ctx = {}) {

  return {
    intent: p.i,
    options: p.options,
    command: p.command ? { display: p.command.display, argv: p.command.argv, cwd: p.command.cwd } : null,
    forecast: p.forecast ?? null,
    budget: p.budget,
    guards: p.guards,
    resume: p.resume,
    hint: p.hint ?? null,
  };
}

}
```

```js
export function gate(req, port, token) {
  const hosts = [`127.0.0.1:${port}`, `localhost:${port}`];
  if (!hosts.includes(req.headers.host ?? '')) return [403, 'forbidden host'];
  const origin = req.headers.origin;
  if (origin !== undefined && !hosts.some((h) => origin === `http://${h}`)) return [403, 'forbidden origin'];
  if ((req.url ?? '/').split('?')[0].startsWith('/api/')) {
    const m = /^Bearer ([0-9a-f]{64})$/.exec(req.headers.authorization ?? '');
    if (!m || !timingSafeEqual(Buffer.from(m[1]), Buffer.from(token))) return [401, 'missing or wrong token'];
  }
  if (req.method === 'POST' && !/^application\/json\b/i.test(req.headers['content-type'] ?? '')) return [415, 'POST needs Content-Type: application/json'];
  return undefined;
}

function readBody(req) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    req.on('data', (c) => {
      size += c.length;
      if (size > MAX_BODY) {
        reject(fail(413, 'body too large'));
        req.destroy();
      } else chunks.push(c);
    });
    req.on('end', () => {
      if (!chunks.length) return resolve({});
      try {
        const body = JSON.parse(Buffer.concat(chunks).toString('utf8'));
        if (!body || typeof body !== 'object' || Array.isArray(body)) return reject(fail(400, 'body must be a JSON object'));
        resolve(body);
      } catch {
        reject(fail(400, 'body is not valid JSON'));
      }
    });
    req.on('error', reject);
  });
}

export function createHqServer({ token }) {
  if (!/^[0-9a-f]{64}$/.test(String(token))) throw new Error('token must be 64 hex characters');
  const server = createServer(async (req, res) => {
    try {
      const denied = gate(req, server.address().port, token);
      if (denied) return send(res, denied[0], { error: denied[1] });
      const path = (req.url ?? '/').split('?')[0];
      if (req.method === 'GET' && Object.hasOwn(STATIC, path)) {
        const [file, type] = STATIC[path];
        return send(res, 200, readFileSync(join(UI, file)), type);
      }
      if (!path.startsWith('/api/')) return send(res, 404, { error: 'not found' });
      if (req.method !== 'GET' && req.method !== 'POST') return send(res, 405, { error: 'method not allowed' });
      const body = req.method === 'POST' ? await readBody(req) : undefined;
      for (const [method, re, fn] of ROUTES) {
        const m = re.exec(path);
        if (m && method === req.method) return send(res, 200, await fn(m, body));
      }
      return send(res, 404, { error: 'not found' });
    } catch (err) {
      const status = Number.isInteger(err.status) ? err.status : 500;
      send(res, status, { error: status === 500 ? `internal error: ${err.message}` : err.message, ...(err.guards ? { guards: err.guards } : {}) });
    }
  });
  return server;
}

// Binds 127.0.0.1 on port, else the next 10 ports; port 0 picks an ephemeral one.
export function listen(server, { port = 4747 } = {}) {
  return new Promise((resolve, reject) => {
    let p = port;
    let left = port === 0 ? 1 : 11;
    const attempt = () => {
      const onError = (err) => {
        if (err.code === 'EADDRINUSE' && --left > 0) {
          p += 1;
          attempt();
        } else reject(err);
      };
      server.once('error', onError);
      server.listen(p, '127.0.0.1', () => {
        server.off('error', onError);
        resolve(server.address().port);
      });
    };
    attempt();
  });
}
```

```js
    else if (k === 'style' || k.startsWith('on')) continue;
    else el.setAttribute(k, v === true ? '' : String(v));
  }
  for (const c of children.flat(Infinity)) {
    if (c === undefined || c === null || c === false) continue;
    el.append(c instanceof Node ? c : document.createTextNode(String(c)));
  }
  return el;
}

export function safeHref(v) {
  const s = String(v);
  return s.startsWith('#/') || s.startsWith('https://') ? s : '#/';
}

export function link(href, ...children) {
  const external = String(href).startsWith('https://');
  return h('a', { href, target: external ? '_blank' : undefined, rel: external ? 'noopener noreferrer' : undefined }, ...children);
}

export const light = (color, label) => h('span', { class: `light ${color ?? 'grey'}` }, label ?? '');
export const stateLight = (state, label = state) => h('span', { class: `light ${LIGHT[state] ?? 'grey'}`, title: label }, `${GLYPH[state] ?? '○'} ${label}`);
export const planLight = (status) => light(PLAN_LIGHT[status] ?? 'grey', status ?? 'unknown');

export function progress(green, total) {
  const bar = h('span', { class: 'bar', role: 'progressbar', 'aria-valuemin': '0', 'aria-valuemax': String(total || 0), 'aria-valuenow': String(green || 0) });
  const fill = h('span', { class: 'green' });
  fill.style.width = `${total ? Math.round((100 * (green || 0)) / total) : 0}%`;
  bar.append(fill);
  return bar;
}

export function ago(iso) {
  const t = Date.parse(iso ?? '');
  if (!Number.isFinite(t)) return '';
  const s = Math.max(0, Math.round((Date.now() - t) / 1000));
  if (s < 60) return `${s}s ago`;
  if (s < 3600) return `${Math.round(s / 60)}m ago`;
  if (s < 86400) return `${Math.round(s / 3600)}h ago`;
  return `${Math.round(s / 86400)}d ago`;
}

export function duration(ms) {
  if (!Number.isFinite(ms) || ms < 0) return '';
  const m = Math.round(ms / 60000);
  return m >= 60 ? `${Math.floor(m / 60)}h ${m % 60}m` : `${m}m`;
}

export const tilde = (path) => String(path ?? '').replace(/^\/(Users|home)\/[^/]+/, '~');

export async function openPath(path) {
  return api('/api/open', { method: 'POST', body: { path } });
}

export const empty = (text) => h('p', { class: 'empty' }, text);
export const errorBox = (err) => h('p', { class: 'error', role: 'alert' }, err?.message ?? String(err));
```
